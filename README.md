# KŌDŌ — сайт домашней парфюмерной мастерской (демо)

Витрина авторских ароматов «по мотивам» мировых брендов + панель мастера, где он сам добавляет ароматы, фото, цены, хиты и меняет тексты сайта. Ташкент, заказы — через Telegram.

## Запуск

Нужен только Node.js 18+ (внешних зависимостей нет, `npm install` не требуется).

```bash
npm start
```

- Сайт: http://localhost:3000
- Панель мастера: http://localhost:3000/admin
- Демо-пароль панели: `katana` — сменить в разделе «Безопасность» (панель будет напоминать, пока пароль не сменён).
- В той же Wi‑Fi сайт открывается и с телефона: сервер печатает адрес вида `http://192.168.x.x:3000`. Windows может спросить разрешение для Node в брандмауэре.

При первом запуске создаётся папка `data/` с демо-каталогом (14 ароматов).
Чтобы начать с чистого листа — остановите сервер и удалите `data/`.

## Показать демо мастеру на телефоне

### Netlify или GitHub Pages — постоянная бесплатная ссылка (рекомендуется)

```bash
npm run build:static
```

Команда собирает папку `dist/` — статическую версию сайта с текущим каталогом. Сервер для неё не нужен, поэтому её можно выложить на любой бесплатный хостинг. Витрина работает полностью (каталог, корзина, заказ в Telegram), а панель мастера — в **демо-режиме**: вход по любому паролю, правки и фото сохраняются только в браузере того, кто их делает, и на витрине видны только на его устройстве (там же кнопка «Вернуть как было»). Мастер может спокойно всё потрогать.

**Netlify (1 минута):**
1. Откройте https://app.netlify.com/drop и войдите (бесплатно, через GitHub, Google или почту).
2. Перетащите в окно папку `dist`.
3. Готово: ссылка вида `https://случайное-имя.netlify.app`. Имя можно поменять: Site configuration → Change site name, например `kodo-parfum` → `https://kodo-parfum.netlify.app`.
4. Обновить после правок: снова `npm run build:static`, затем в Netlify → Deploys → перетащить новую папку `dist`.

**GitHub Pages:**
1. Создайте на GitHub публичный репозиторий, например `kodo-parfum`.
2. «uploading an existing file» → перетащите **содержимое** папки `dist` (файлы и папки внутри неё) → Commit changes.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Через минуту сайт будет на `https://ЛОГИН.github.io/kodo-parfum/`.

### Временная ссылка с вашего компьютера: `npm run share`

```bash
npm run share
```

Поднимает сайт с настоящей панелью мастера и бесплатный туннель [localhost.run](https://localhost.run) — без регистрации, нужен только `ssh` (он есть в Windows 10/11). В консоли появятся ссылка `https://xxxx.lhr.life` и QR-код для телефона.

- Работает, пока открыто окно и компьютер не спит; при каждом запуске ссылка новая. Бесплатный туннель иногда обрывается — тогда запустите заново.
- Панель мастера по ссылке тоже доступна (`…/admin`) — перед тем как отправлять ссылку, смените демо-пароль.
- Если `npm start` уже запущен, сначала остановите его: `share` сам поднимает сайт.

### Полная версия онлайн: Render

Настоящая панель мастера с сервером, а не демо-режим. Нужны бесплатные аккаунты GitHub и [Render](https://render.com).

1. Создайте на GitHub пустой репозиторий и загрузите туда проект (папка `data/` в git не попадёт — так и нужно):
   ```bash
   git init && git add . && git commit -m "Сайт мастерской" && git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/kodo-parfum.git && git push -u origin main
   ```
2. Render → **New → Blueprint** → выберите репозиторий. Настройки уже лежат в `render.yaml`; Render спросит только `ADMIN_PASSWORD` — пароль панели для онлайн-версии.
3. Через пару минут будет адрес вида `https://kodo-parfum.onrender.com`.

Особенности бесплатного тарифа: без посетителей сайт засыпает через 15 минут, первое открытие после этого занимает около минуты; при перезапуске данные возвращаются к демо из `lib/seed.js` (изменения из панели не сохраняются). Для показа это нормально, для настоящей работы — см. «Публикация» ниже.

## Что умеет

**Витрина**
- Хиты продаж, каталог с поиском (по названию, бренду, нотам), фильтрами и сортировкой, прайс-лист одной таблицей.
- Карточка аромата: ноты (верх/сердце/база), стойкость и шлейф, выбор объёма и количества.
- Корзина → кнопка «Оформить» открывает Telegram мастера с готовым текстом заказа (и копирует его в буфер).
- Ссылка на конкретный аромат (`/?aroma=syogun`) — со своим заголовком и фото в превью Telegram.
- «Не нашли свой аромат?» — запрос мастеру на аромат под заказ.
- Блоки «О мастере» (барбер · фехтование · парфюмерия), «Студия», «Как заказать», FAQ, контакты.
- Вместо фото можно показать нарисованный флакон — каталог выглядит цельно с первого дня.

**Панель мастера**
- Вход по паролю, защита от перебора (8 ошибок → пауза 15 минут).
- Добавление/редактирование ароматов. Картинка на сайте — на выбор:
  - **Флакон**: 8 форм (классика, круглый, высокий, кристалл, куб, арка, капля, пирамида), 14 готовых цветов или любой свой, 6 крышек (чёрная, золото, дерево, серебро, красный лак, жемчуг);
  - **Своё фото**: кнопкой, перетаскиванием или Ctrl+V. Фото сжимается в браузере (до 1600 px, WebP), так что снимки с телефона не тормозят сайт.
- Быстрые переключатели «Хит», «В наличии», «На сайте», порядок стрелками.
- Все тексты сайта, достижения, FAQ, контакты, фото мастера.
- Смена пароля, выход на других устройствах.

## Устройство

```
server.js            HTTP-сервер: витрина, API, загрузка фото, безопасность
lib/store.js         хранилище (data/db.json, атомарная запись)
lib/auth.js          пароль (scrypt) и сессии (подписанная cookie)
lib/sanitize.js      проверка и очистка всех данных из панели
lib/seed.js          демо-данные для первого запуска
scripts/share.js     временная публичная ссылка (npm run share)
scripts/build-static.js  статическая версия для Netlify / GitHub Pages → dist/
lib/render.js        сборка главной страницы (общая для сервера и статической версии)
render.yaml          настройки бесплатного хостинга Render
public/index.html    витрина (данные вшиваются сервером)
public/assets/       стили, скрипты, SVG-иллюстрации (флаконы, катана)
public/admin/        панель мастера
data/                база, фото, ключ сессий — НЕ в git, бэкапить отдельно
```

Хранилище — один JSON-файл. Для каталога в десятки–сотни ароматов этого достаточно; бэкап = копия папки `data/`.

## Публикация

Для настоящей работы нужен сервер с постоянным диском: VPS (от ~$5 в месяц) или Render с платным диском. На бесплатных хостингах со «стираемым» диском пропадут фото и база.

1. Node.js 18+, скопировать проект, `npm start` под `pm2` или `systemd`.
2. Перед сервером — Caddy или nginx с HTTPS и доменом.
3. Переменные окружения (все необязательные):

| Переменная | Зачем |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `HOST` | `127.0.0.1`, если сервер стоит за nginx/Caddy |
| `DATA_DIR` | где хранить базу и фото |
| `ADMIN_PASSWORD` | пароль при самом первом запуске (вместо демо) |
| `SITE_URL` | `https://домен` — для правильных ссылок в превью Telegram |
| `TRUST_PROXY=1` | за прокси: брать IP посетителя и адрес сайта из заголовков `X-Forwarded-*` |

## Юридическая оговорка

На сайте у ароматов свои названия, а оригинал указан только как «по мотивам …»; в подвале — дисклеймер, что это не продукция брендов. Не стоит использовать фото оригинальных флаконов и логотипы брендов — только свои фото.
